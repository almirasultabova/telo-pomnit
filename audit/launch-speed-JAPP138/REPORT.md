# J-APP-138 — загрузка заставки и заполнение экрана

19 октября2026. T-APP-037, связь с приёмкой J-APP-137/T-APP-036/I-066. **Кандидат принят и опубликован J-APP-139.** [Выпуск и возврат](../launch-speed-release-JAPP139/RELEASE.md). Ниже — исходная локальная проверка. База — опубликованный c28b7d45fd1f3ab911c2f31ef96cf0b26c1abac6; общая рабочая папка и выпускная копия не изменялись.

Альмира с iPhone сообщила о долгом ожидании закрытого бутона; уточнила, что зелёные поля сверху и снизу. Точное время, модель, версия iOS/Telegram и сеть неизвестны. Сохранение записи/возврат по J-APP-137 не подтверждены.

В коде: object-fit:contain оставлял фон #3b4735 при несовпадении пропорций; src видео назначался после auth/access. Это подтверждённые свойства реализации; без инспектора телефона нельзя назвать их единственной причиной её задержки.

## Изменения

- Постер, native video и запасной animated WebP теперь используют cover: вся площадь занята изображением, без добавленных полос/растяжения. На иных пропорциях обрезаются края; это следствие прямого пожелания заполнить всю площадь. Название и цветок проверены на390×950 и390×724.
- Выбранный по пропорции MP4 получает src/load при DOMContentLoaded, одновременно с серверным входом. Play остаётся после прежнего ready/authed/owner. Ранний media error до ready только запоминается native video; fallback начинается после допуска. Cancel очищает preload; личные данные/маркер читаются только прежним путём после допуска.
- Два облегчённых MP4: standard561592байта вместо1528381 (−63,3%); tall606111 вместо1862236 (−67,5%). H.264 Baseline,540px по ширине,24fps,faststart,без аудио;4,2с исходного материала покрывают прежние clipEnd4,1/3,6. Цена — разрешение540 вместо720, проверено по реальным кадрам. Форма/цвет/сюжет прежние, без новой генерации.
- Темп6с первого и2,5с повторного входа, animated fallback, пределы загрузки/зависания и ошибка входа прежние. Сокращено ожидание загрузки, движение специально не ускорялось.

Исходники кандидата: `output/launch-speed-JAPP138/source/`. Узкий patch и SHA: [launch-only.patch](launch-only.patch), [manifest.json](manifest.json). Отличаются ровно app/index.html, app/js/launch.js и app/css/launch.css; добавлены два MP4. app.js/api.js/boot.js/storage.js и остальные исходники приложения совпадают с выпускной базой. Изменение общего корневого index.html, касающееся раскрытия инфраструктуры, сюда не переносилось.
