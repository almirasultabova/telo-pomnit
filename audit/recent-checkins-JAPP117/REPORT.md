# Ограниченный старт истории состояний — J-APP-117 / T-APP-026

19 октября 2026. После прямого поручения Альмиры опубликовать J-APP-115 и продолжить следующим пакетом, J-APP-115 выпущен отдельно в J-APP-116. Этот этап уменьшает именно первоначальную передачу checkins; diary пока читается полностью для карты/серии/сводок. Изменения только локальные, три клиентских исходника.

## Поведение

Api.getRecentCheckins использует существующий приватный GET /checkins?limit=201. Текущий backend поддерживает этот предел: SHA-256 опубликованного routes/checkins.js совпал с локальным ca5c5d1b56088937431edef7ea71c1bcd5479b1820da8a97fdb7dc3cd52e7505. Бэкенд и API-контракт не менялись. Меньше201 строки — полная история, ровно201 — консервативно partial; частичный ответ не выдаётся за полный. Неверная форма, больше201 строки, запись без id и смена авторизации отклоняются.

После подтверждённого входа Storage.initFromApi({recentCheckins:true}) получает этот начальный набор. Остальные ресурсы и поколение владельца сохраняются. Старый вызов без аргумента по-прежнему читает полную историю; новая опция не меняет обычный retry J-APP-115. Частичный кэш и pending-редактирования с более новым clientUpdatedAt не удаляются и не перезаписываются.

При входе в «Мой путь» или личную историю состояний вызывается ensureCheckinHistory. Он объединяет одновременные обращения и при необходимости дожидается начального recent-запроса, затем читает полную историю существующими страницами200. Если полный результат уже подтверждён в этой сессии, повторного скана нет. Повторный recent-bootstrap не понижает уже подтверждённый полный статус. После отказа автоматического цикла повторов нет — остаётся явная кнопка.

Пока история неполная, график показывает загрузку без сравнения по отрезанному набору. Личный календарь подписывает доступный кэш «Наблюдения на этом устройстве» и не показывает сравнение до полной загрузки. При отказе второй страницы прежние строки остаются вместе с предупреждением/повтором; «Все личные наблюдения» появляется после полного ответа. Пустая непроверенная история не выдаётся за отсутствие оценок. Действующие стили, пять исходных шкал, их значения/направления/недельные расчёты не менялись.
