# J-APP-091 — рабочее сохранение «После встречи»

18 октября 2026. Альмира приняла J-APP-090 и разрешила перенос в приложение, настоящее сохранение и публикацию с резервной копией. T-APP-009, I-030. Принятый внешний вид сохранён; новый дизайн не предлагается.

Дневник → После встречи → разбор/практика → дата и свободный текст. Три подсказки раскрываются добровольно. Сохранённые заметки доступны в своей группе «После встреч», открываются для чтения и редактирования. В тело/оценки/статистику наблюдений не подмешиваются.

## Данные и права

Отдельная Prisma-модель AfterMeetingNote и добавочная SQL-таблица after_meeting_notes. GET/POST/PUT /after-meeting-notes требуют действующий допуск и всегда выбирают userId из проверенного JWT. Платное зачисление не требуется, как для личного Дневника. Ведущая не получает чужие тексты. Административных маршрутов нового типа нет; AI-контекст не расширен.

POST с уникальным clientId на аккаунт сериализован блокировкой собственной строки User, повторы не дублируют запись. Редактирование использует revision; конфликт с другой версией даёт 409, повтор после потерянного ACK с тем же текстом безопасен. Пустой текст, неверный тип/дата, будущая встреча, длина более 20000 отклоняются сервером. Все ответы нового маршрута private/no-store.

Черновики используют существующий scoped Storage.saveFormDraft и входят в локальную выгрузку formDrafts; при запрете localStorage есть честное предупреждение. Сбой не показывается как успешное сохранение. Первый payload и подтверждённый ID удерживаются после неоднозначных ошибок POST/PUT. Logout сбрасывает видимое состояние, завершение старого запроса не записывает данные новому аккаунту.

Серверная JSON-выгрузка /gdpr/my-data включает только собственные afterMeetingNotes. Существующее удаление аккаунта удаляет их под прежней блокировкой User. PDF «Дневник тела» по-прежнему выгружает телесные наблюдения; новые свободные заметки доступны в JSON и в приложении.

Прежняя локальная разница consent-copy в root app/index.html исключена из выпуска: чистая release-база сохраняет опубликованный текст. Действующий routes/ai.js GPT-4.1 mini закреплён hash e00e35c8a9fd2458e7ed7b62ec8f304dc1a4220c2b8bb58e7279791656e09663 и не заменяется старым AI из Git-базы.
