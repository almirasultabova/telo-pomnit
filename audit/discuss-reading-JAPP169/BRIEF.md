# J-APP-169 — вернуться к своей записи «К разбору»

Operate, узкая доработка действующего интерфейса по разделу6/14 исходного аудита. Основание — baseline.json: Chromium390 список2164→0, WebKit390 3403→0 после Back. Фокус открытой записи/ошибки сохранения уходит на BODY/SECTION. Список при первой ошибке одновременно показывает «Загружаем…» и ошибку.

Результат: возврат к прежней строке/вкладке/позиции; отмена редактирования возвращает к чтению записи; понятные состояния сохранения и ошибки. Тексты записей, черновики и ручная отправка сохраняются. Никакой передачи ведущим. Айдентика, API и backend прежние. Проверить длинный текст, обе вкладки, загрузку/пусто/ошибку/повтор, черновик и поздний ответ после выхода. Только локально до следующего согласования.
