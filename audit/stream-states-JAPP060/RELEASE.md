Срок — три календарных месяца после последнего дня потока, по конец дня Москвы; короткий месяц корректно ограничивает день. После срока URL не выдаётся; индивидуальный expiry имеет приоритет. Реальное наличие всех записей в группе этим выпуском не проверяется.

Ошибка доступа/отсутствие потока/будущий поток имеют прежние безопасные состояния. Неправильная ссылка Telegram блокируется; поздний/отсоединённый элемент и элемент после смены owner/generation/потока не выполняет переход; клик после срока вызывает обновление доступа.
