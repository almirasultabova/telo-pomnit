# J-APP-147 / T-APP-041 — UI, тексты и согласованность форм

19 октября2026. Прямое поручение Альмиры после уточнения J-APP-146: «Да, давай следующий пакет — UI, тексты и визуальная согласованность по аудиту». Реализован локальный кандидат поверх опубликованной версии500f5b6. Production, Git commit/push, серверные данные и платные API не менялись.

## Результат

- **Форма реакции:** «Моя реакция», «Что произошло?», «Опишите ситуацию так, как вам удобно», «Как вы отреагировали?», «Насколько сильной была реакция?». Подсказка заметки также на «вы». Типы реакций, шкала1–10, исходное значение, способ выбора, поля payload и сохранение не менялись. Группа реакций получила связь с видимой подписью.
- **Начальная анкета:** системный alert заменён сообщением рядом с кнопками, с role=alert/фокусом и повтором отправки. Сообщается отсутствие подтверждения, а не заведомое отсутствие серверной записи. Ответы остаются в форме; в сообщение не вставляется необработанный текст ошибки сервера. Уход со страницы и смена контекста не вызывают всплывающую ошибку поверх другого экрана.
- **Обратная связь:** такой же компонент ошибки, сохранённый ввод и кнопка повтора. Повтор неизменённого сообщения сохраняет operationId; новый текст получает прежним механизмом новую операцию. Отказ старой отправки не перекрывает новый черновик или вновь открытую форму. Busy-состояние отражено в aria-busy.
- **Необязательная оценка:** добавлена «Убрать оценку», понятная подпись и статус. Сброс сохраняется в черновике, серверный payload получает прежнее допустимое null. После исчезновения кнопки фокус переходит к первой звезде.
- **Визуальная согласованность:** общий компонент сообщения использует имеющиеся токены цветов/интервалов/радиусов. Заголовок и кнопка возврата обратной связи согласованы с соседними формами, кегль28px сохранён. Место под управление оценкой не скачет после её выбора. Прокрутка показывает ошибку и кнопку повтора вместе, с запасом под нижнюю область приложения.
- **Сводка «Моего пути»:** «Главная зона потока» заменена частотной подписью «Чаще всего вы отмечали область». Расчёт сводки проверен сравнением функций: изменена только строка текста.

Файлы: app/index.html, app/js/app.js, app/js/api.js; новые app/js/form-messages.js и app/css/form-consistency.css. Модуль сообщения не сохраняет и не отправляет данные; при навигации и выходе очищает только собственные сообщения. Все остальные исходники приложения, backend и медиа из снимка503файлов неизменны. Случайная ранее существовавшая root-правка disclosure в HTML исключена из кандидата.

## Проверки

66групп: Chromium320/390/768/1440 и WebKit390, дополнительно увеличенный вдвое текст сообщения/кнопки и поздний отказ анкеты после ухода. Проверены обычный выбор реакции, необязательная оценка/сброс/черновик,503/повтор/успех двух форм, идентичность операции и payload, новый текст во время запроса, повторное открытие, блокировка двойной отправки, фокус/role, навигация анкеты, короткий viewport430px, доступность кнопки для нажатия, очистка при выходе и подпись сводки. Native dialogs и ошибки JavaScript0; горизонтальное переполнение не обнаружено. [Результаты](ui-results.json).

При визуальном проходе обнаружено низкое положение кнопки обратной связи после ошибки. Исправлены scroll-padding и показ сообщения вместе с кнопкой; добавлены проверки фактического попадания кнопки под указатель. После общей правки повторён целевой набор. Уточнения тестовых фикстур: сбор формы добавляет пустые необязательные поля, а действующая благодарность использует q-completion; тесты согласованы с настоящим интерфейсом без изменения его контрактов.

Сборка96публичных файлов; структура64HTML/CSS/JS без предупреждений, node --check изменённых JS прошёл. Scoped Impeccable layout detector:[]; проверены реальные кадры Chromium/WebKit и соседние формы. Палитра, шрифты и основной компактный масштаб сохранены. Пара цвета ошибки/бумажной поверхности проверяется штатными токенами; полного нового WCAG-аудита не проводилось.

Локальный просмотр проверен отдельно без Playwright-перехвата API: собственный учебный HTTP-сервер показывает намеренный первый отказ и успешный повтор сообщения/анкеты. Его переход на выбранный экран выполняется после окончания начального входа; прежний ранний переход фикстуры мог быть перезаписан startup, это исправлено только в preview.py. Настоящие серверы/аккаунты/AI/уведомления не используются.
