## Что работает

В Профиле появился «Обзор потока». Согласованная композиция перенесена в отдельную same-origin страницу внутри существующей оболочки с возвратом в Профиль. JWT остаётся в памяти родителя, в URL/хранилище обзора не передаётся. Нет демонстрационного переключателя ведущих, вымышленных чисел или fallback на учебные данные.

Владелец видит доступные потоки; подтверждённый аккаунт Анастасии получил отдельное разрешение на октябрьский поток. Сам по себе HOST/ADMIN не даёт доступ. Полное управление Анастасии не открывалось. В каждое чтение/изменение входит серверная проверка; при отзыве grant старый токен не сохраняет доступ. Прямой URL без родительской сессии показывает отказ, а API без JWT отвечает 401.

Подключены именные статусы анкет, агрегаты двух сопоставимых шкал и фиксированных ответов итоговой анкеты. Нет доступа к личным текстам анкет, дневнику или AI-переписке из обзора. В форме обратной связи — поток, тема и явный выбор необходимости ответа. Старый клиент совместим; прежние сообщения без определённого потока/намерения остаются отдельными для ручного разбора владельцем. Взять в работу/отметить ответ — атомарные действия с revision и журналом; чужого ответственного не перезаписать, отметка ответа требует подтверждения. Реальная переписка открывается только по доступному корректному Telegram username; кнопка отметки сама ничего не отправляет.
