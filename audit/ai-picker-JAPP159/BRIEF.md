# J-APP-159 / T-APP-047 / I-074 — выбор записей для AI

20 октября2026. По прямому поручению Альмиры продолжить дизайн/удобство после выпуска J157. Источник — исходный аудит18октября, раздел6 «AI: выбор дневника и просмотр контекста» и раздел14 завершающей полировки.

До: после Space на checkbox фокус переходит на BODY; проблема воспроизведена в Chromium/WebKit. Количество выбранных не видно, выбранная строка отличается только маленькой галочкой, лимит сообщается после попытки выбрать шестую.

Локальный результат: счётчик «Выбрано: n из5», выделение выбранных строк, понятное объяснение достижения лимита; при пяти неподмеченные недоступны до снятия одной отметки. После выбора сохраняются фокус и прокрутка списка. Явный просмотр выбранного переводит внимание к полному тексту; разрешение использования по-прежнему отдельное, до отправки.

Предельные5/без дневника/точный текст/добровольное разрешение/отправка только явно сохранены. Провайдер, модель, backend и контракты API не меняются. Никакие рабочие записи и реальный AI для проверки не используются. Следующий пакет локально до отдельного поручения на выпуск.
