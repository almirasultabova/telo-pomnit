# Переработка Профиля — J-298 / T-030

11 октября 2026. Источник: скриншот финальной бежевой плашки и прямое поручение Альмиры «этот блок надо сделат и в целом весь раздел профил исправить, переработать». Сохраняется согласованная молочная/шалфейная/изумрудная палитра, Cormorant Garamond и Manrope. Это полный пересмотр композиции Профиля в действующей айдентике, без новых функций.

## Новая композиция

Личный профиль первым: подтверждённое имя, прежний реальный аватар/инициал, существующая цитата. Согласие остаётся доступно; приватность перемещена в собственный слот под личным блоком, обработчик открытия неизменный. Показатели из Storage оформлены спокойной строкой с разделителями вместо массивной шалфейной заливки.

Свой поток, подтверждённый статус анкеты, доступ и расписание собраны в отдельную группу. Пустой раздел доступа скрыт только когда нет ни Zoom/чата, ни видимой кнопки; серверные ограничения не меняются. Обновление доступа и выбор потока сохранены. Существующие даты/описания/подготовка встреч раскрываются по прежним правилам.

Ведущие оформлены строками с фотографиями, именем, ролью и прежней Telegram-ссылкой. Обратная связь отдельным действием. Финальная реплика «Ты уже делаешь достаточно» на ткани fabric-sage-owner.webp, присланной владельцем и уже использованной в Дневнике; без плоской бежевой плашки, без новых медиа и выдуманных данных. Анкетная иконка отображается SVG, текст/сценарий не изменён.

Административная работа J-299 параллельно завершилась отдельным коммитом 8b1b746. Его скрипт, точка входа, права и обработчики возврата сохраняются; не включаются в собственный diff этой визуальной задачи. HTML/JS изменены только для группировки и перемещения кнопки приватности. Backend, API, оплата, методика и структура личных данных не меняются.

## Проверка

Проверены один экземпляр приватности в новом слоте, порядок блоков, фон финальной реплики, обратная связь и Telegram BackButton, список только собственных потоков, синхронизация выбора, архив, реальные описания/подготовка в тестовом API, допуск Zoom, участие и клавиатура анкеты. Пустой доступ скрыт без потока/при ошибке. Служебное состояние проверено с синтетическим аккаунтом, реальные админ-заявки не читались.
