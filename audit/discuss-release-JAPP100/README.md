# «К разбору» — настоящее личное сохранение J-APP-100 / T-APP-012

18 октября2026. Альмира приняла название/просмотр JAPP099, разрешила перенос и публикацию с резервной копией. Только для владелицы, без отправки ведущим, OpenAI и уведомлений. [Источник](../../База%20знаний/Источники/Разговоры/2026-10-18-принять-и-опубликовать-К-разбору-JAPP100.md). Фактический статус публикации/откат — [RELEASE.md](RELEASE.md).

## Реализация

Новая additive таблица DiscussionNote: свой текст, необязательный независимый snapshot выбранного фрагмента, готово/обсудили, clientId/revision и даты. Источник проверяется на принадлежность текущему пользователю; метка/дата исходника выводятся сервером. Полная заметка не копируется. Изменение/удаление исходника не переписывает сохранённый фрагмент. Передачи ведущим/AI нет, командные grants не расширены.

GET/POST/PUT /discussion-notes — requireAuth + request.user.id, User-lock при изменениях, user/clientId-идемпотентность и revision для конфликтов. Другой аккаунт, включая ведущую, не получает чужой список или запись; private/no-store. Собственная JSON-выгрузка/удаление аккаунта учитывают модель. Автоматического связывания с открытыми обращениями нет.

Дневник: «К разбору» → Написать / Из заметки → Сохранить для себя. Реальная собственная история с пагинацией, выбор конкретного фрагмента либо всей записи с сокращением; оригинал не меняется. Можно сохранить только фрагмент. Два списка «К встрече»/«Обсудили», обратная отметка, редактирование. Ближайший разбор берётся из актуального разрешённого расписания, показывается только при наличии.

Черновик на устройстве привязан к аккаунту. Pending payload фиксируется до запроса; успех после проверенного ACK. При потерянном ответе повтор не создаёт вторую запись. Если после ошибки изменён текст, сначала подтверждается прежняя версия, изменения сохраняются отдельным черновиком без автоматической отправки.409 сохраняет черновик и требует явного обновления/сравнения. Logout/смена пользователя инвалидируют результаты и очищают приватный DOM. Сохранение в аккаунте не обещается до успешного ответа сервера.
