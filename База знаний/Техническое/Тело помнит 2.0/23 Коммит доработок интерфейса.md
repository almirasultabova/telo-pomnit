app/index.html, app/css/styles.css, app/js/app.js, app/DESIGN.md; media/app/redesign/leaf-shadow-owner.webp; технические отчёты 20, 21 и 22 и этот протокол. Фон двух светлых карточек Главной — присланное владельцем изображение теней листвы.

## Проверки и границы

Предыдущие проверки J-285: 12 сценариев, 6 проверок контраста и 2 ошибки загрузки. J-286: 12 сценариев форм и 2 сбоя отправки. J-287: 18 браузерных случаев. Все выполнялись с изолированным тестовым API; физический Telegram и настоящий production backend этими результатами не подтверждаются. Перед коммитом проверены diff, отсутствие посторонних файлов в индексе, node --check и git diff --cached --check.

Открытое ограничение анкеты при смене потока описано в отчёте 22; визуальная доработка его не устраняет. Общая рабочая копия содержит чужие изменения, поэтому не используется git add -A. Push в main выполняется без force. Этот Git-коммит не подтверждает отдельный выпуск на резервный Beget; состояние Vercel после отправки проверяется отдельно.
