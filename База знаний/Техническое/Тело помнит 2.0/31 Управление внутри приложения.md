# Управление внутри приложения — J-299 / T-034

11 октября 2026. Источник: прямое уточнение Альмиры «я имела ввиду в приложении», затем «давай».

В профиль добавлен вход «Управление», видимость и открытие подтверждает GET /access-admin/session. Вложенная панель использует текущий memory JWT, без токена в URL/storage и повторного Telegram auth. Каждый API защищён сервером. Владелец и approved ADMIN управляют; HOST/участницы не получают доступ. Назад возвращает в профиль и удаляет iframe. Выход/смена аккаунта/отзыв прав удаляют панель; source+origin защищают сообщения готовности. Сбой проверки/загрузки имеет повтор.

Панель сохраняет заявки, людей, потоки, историю решений и агрегаты использования. Личные тексты дневника не показываются в агрегатах. Уведомления бота J-297 сохраняются.

Проверка и публикация выполняются. Физическая приёмка на телефоне не проведена.
