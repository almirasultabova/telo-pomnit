## Проверенная исходная точка

В app/js/app.js switchTab('diag') вызывает ensureDiaryHistory и ensureCheckinHistory: догружаются оба личных архива. Затем inStreamPeriod/selectedCheckins и renderMyPathTab отбирают записи выбранного потока по его московским датам. Сводка дневника и график ожидают глобальную полноту. После J-APP-127 Дневник уже читает нужный сегодняшний день; аналогичный принцип ещё не применён к «Моему пути».

GET /diary поддерживает from/to. GET /checkins пока поддерживает только limit/offset — для уменьшения объёма оценок потребуется узкое дополнение серверного чтения с сохранением прежнего ответа без фильтров. Это не готовая функция. Backend/Prisma/публичные файлы в этом ходе не менялись.

## Предлагаемый результат

- Вход в «Мой путь» запрашивает собственные дневниковые записи и оценки состояния только за даты выбранного потока. Без выбранного потока полный архив не запускается ради пустой аналитики.
- Появляется отдельный статус полноты owner/generation/stream/периода. Полный выбранный период не означает полную личную историю. Частичный ответ/ошибка не выдаётся за достоверный график или пустую карту.
- При переключении потока старый поздний ответ не подменяет новый результат. Повторный вход в уже загруженный период не перечитывает архив; текущие сохранения/обновление/повтор учитываются.
- Пять шкал, недельные средние, границы периода, прежние записи без streamId и отбор записей другого потока сохраняют текущий смысл. Pending/ACK, общий накопленный кэш, поиск/«Важное» и отдельная полная история остаются согласованными.

## Приёмка

На искусственном большом архиве передаются только строки выбранного периода; графики/сводка/карта совпадают с прежним расчётом по полному архиву. Проверяются старый и текущий поток, отсутствие потока, пересекающиеся даты, границы по Москве, переключение во время чтения, отказ второй страницы/retry, сохранение во время чтения, смена владельца и полная история по отдельному обращению. Серверное чтение проверяется на отдельной PostgreSQL-базе; интерфейс — в Chromium/WebKit. Фактическое ускорение телефона до измерения не обещается.
