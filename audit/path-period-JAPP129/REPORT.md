# J-APP-129 / T-APP-032 / I-062 — выбранный период «Моего пути»

19 октября 2026. По прямому поручению Альмиры реализация и публикация выполнены выпуском J-APP-130. Изменены только app/js/api.js, storage.js, app.js и backend/src/routes/checkins.js. Дизайн, тексты экранов, формулы графиков, пять шкал, права, Prisma и AI сохранены.

При открытии «Моего пути» загружаются дневниковые записи и оценки состояния за московские даты выбранного потока. GET /checkins получил необязательные from/to; прежний ответ без фильтра совпадает с прежним кодом побайтно на одной тестовой базе. Дневник использует существующий фильтр. API проверяет полноту страниц и попадание дат в запрошенный полуоткрытый период [start,end); сервер получает from=start и to=end-1ms.

Полнота периода хранится отдельно по owner/generation/stream/start/end и независимо для дневника/оценок. Без потока запросов нет. Повторный вход в подтверждённый период не перечитывает данные; ошибка требует явного повтора только нужного ресурса. График/сводка не выдаются за полные при ошибке или частичном чтении. Позднее чтение покинутого периода игнорируется; повторный выбор корректно загружает его. Перемена дат того же потока создаёт новый scope.

Общий кэш объединяется без удаления прежних строк; pending и новый ACK дневника сохранены. Чтение оценок не заменяет более свежую локальную версию, включая уже подтверждённый ACK. Поиск, «Важное», полный календарь/история и собственные выгрузки остаются отдельными сценариями. Начальные окна 91/201 и компактный индекс дней не менялись. Первый вход в период делает его запросы даже при наличии глобального кэша; кэш сам по себе не является доказательством полноты выбранного периода.
