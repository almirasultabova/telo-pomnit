## Что это за проект

**«Тело помнит»** — онлайн-программа интегративной телесной терапии.

Психосоматика + телесная терапия + внедрение в реальную жизнь.
5 недель, 9 живых встреч, Zoom + закрытый Telegram-чат.

## Доработка концепции по аудиту — 22 сентября 2026

- Стоимость доступна с первого экрана и через компактную закреплённую ссылку; последняя скрывается у hero, условий и футера.
- Выбор ситуации показывает контекст, возврат к вариантам и открывает соответствующую неделю. Выбор никуда не отправляется.
- Telegram принимает имя и ссылку на профиль; внутри формы есть прямой контакт при отсутствии username или сбое сети. Без JS кнопки ведут напрямую в Telegram.
- Средний блок показывает три шага одного примера; приложение представлено демонстрационным наблюдением с раскрываемым настоящим скриншотом.
- Елена/Наталья — пересказы `Кейсы и отзывы/Кейсы.pdf`, НЕ дословные цитаты. Отдельно показан оригинальный отзыв об индивидуальной консультации (`photo_11_2026-03-04_00-49-32.jpg`), без приписывания групповой программе.
- Подготовка Анастасии взята из переданных ею сведений в соседнем проекте `anastasia_khoroshavseva/.../docs/CONTENT_SOURCE.md`. Сканы дипломов ещё не сверены, государственные квалификации не заявляем.
- Старые PDF дают ориентиры около 2 часов и 3 месяца доступа к записям, но актуальность для октября не подтверждена; эти сроки не опубликованы как обещание. Срок доступа к приложению также требует подтверждения.
- Аналитические события подготовлены, но не активированы: новая страница не загружает Метрику. `trackGoal` требует `window.tpAnalyticsConsent === true` и существующий `window.ym`. Перед включением нужны согласованный механизм выбора, актуализация политики (сейчас там заявлено отсутствие tracking cookies) и проверка целей в счётчике. Контакты и выбранные ситуации не передаются.

### Надёжность заявок

`WaitlistEntry` хранит очередь доставки: `notificationPending`, `notificationRetryAt`, `notificationAttempts`, `notifiedAdminIds`. Новые заявки включаются в очередь сразу при сохранении; старые не переотправляются. Мгновенную отправку дополняет cron раз в минуту. Повторы только недоставленным получателям, интервалы 1/5/15/60/360 минут, резерв записи 10 минут. Возможны дубли при остановке между отправкой в Telegram и фиксацией результата; ID заявки позволяет их различать.

`GET /admin/waitlist` и вкладка «Заявки» доступны только администраторам. Это контроль сохранения/уведомлений, не CRM со статусом ответа ведущей. Для обновления backend сначала выполнить точечный SQL из `TESTING.md`, затем `prisma generate`, обновить JS и перезапустить PM2. Не применять `db push` к production вслепую.

### Запись на поток — сейчас через заявку, не прямую оплату

Кнопки записи на лендинге ведут в заявку: модалка (email + Telegram) → `POST /waitlist` → запись в БД (`WaitlistEntry`) → уведомление админам в Telegram. Анастасия связывается с участницей в течение дня, отвечает на вопросы и отправляет ссылку на оплату. Оплата через ЮКассу (`payment.js`, `POST /create-payment`) технически работает, но напрямую к лендингу не подключена.

## Технический стек

### Frontend (лендинг)
- Vanilla HTML/CSS/JS, без зависимостей
- Продакшн: Beget VPS, nginx, `/var/www/telo-site`
- Vercel сохранён как резервная копия; DNS продакшн-домена на него не указывает

### Telegram Mini App
- Vanilla JS SPA
- Авторизация через Telegram initData + JWT
- API-первый подход (данные на сервере)

### Backend
- Node.js 20 + Fastify + Prisma + PostgreSQL
- Grammy (Telegram бот) + node-cron (напоминания)
- JWT авторизация через Telegram initData
- PM2 (процесс-менеджер) + Nginx (reverse proxy)
- Let's Encrypt SSL
- Nodemailer + Яндекс SMTP (welcome-письма)
- ЮКасса API (приём платежей, webhook)
- OpenAI GPT-4o-mini (AI-ассистент)

## Безопасность

| Компонент | Меры защиты |
|---|---|
| CORS | Основной: `app.telo-pomnit.ru`, `telo-pomnit.ru`, `web.telegram.org`; резерв: `almirasultabova.github.io`, `tg-app-telo-pomnit.vercel.app` |
| Авторизация | HMAC-SHA256 с `timingSafeEqual`, проверка `auth_date` (макс. 24ч), JWT 7 дней |
| Webhook ЮКасса | IP-фильтр по официальным подсетям ЮКасса |
| AI-сессии | Проверка `session.userId === request.user.id` перед доступом |
| Входные данные | `maxLength` на email (254), name (100), telegramUsername (64) |
| Dev-режим | Удалён — `|| 'dev'` fallback убран из `api.js`, `auth.js` |
| База данных | PostgreSQL на Beget VPS, доступ только через backend API |
| Согласие ФЗ-152 | `PATCH /me/consent` сохраняет дату+текст; синхронизируется между устройствами через `consentGivenAt` в ответе `POST /auth/telegram` |
| pending_enrollments | Cron (03:00 МСК) удаляет незавершённые оплаты старше 60 дней |
