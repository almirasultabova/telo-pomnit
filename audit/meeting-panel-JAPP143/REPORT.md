# J-APP-143 — встреча, участие и запись

По выбору Альмиры реализован вариант1 J-APP-142. В расписании одна кнопка перехода с датой, темой и спокойным статусом «Участвовала». Отметка и отмена находятся в отдельном окне встречи. Сохранены описание, подготовка, временной диапазон и прежние условия ссылки прямого Zoom.

Для записи добавлены два nullable поля Meeting; отдельная точная SQL-миграция. API отдаёт ссылку и код только при существующем доступе к материалам потока. Оба ответа с программой имеют `private, no-store`. Нового владельческого редактора нет: Альмира передаёт данные для адресного внесения.

Внутри встречи: «Запись эфира», код и копирование. При запрете буфера код выделяется с понятным пояснением. Внешние значения вставляются через textContent/value, разрешена HTTPS-ссылка без credentials. Закрытие, смена аккаунта/поколения/потока и возврат защищают контекст. Native dialog удерживает фокус; после закрытия возврат к строке встречи, после отметки — к той же кнопке. Длинное содержание прокручивается отдельно, закрытие и действие остаются доступны. Вызов анкеты по таймеру не перекрывает окно встречи.

Проверено на вымышленных данных:

- 19 групп в Chromium320/390/1440 и WebKit390: 76 сочетаний; открытие, участие/отмена, Escape/назад, фокус, копирование/отказ/позднее завершение, доступ/срок, смена контекста, длинный текст и безопасный вывод. Ошибок JavaScript и горизонтального переполнения нет.
- 16 групп native Fastify + реальный отдельный PostgreSQL; точная миграция сохраняет прежнюю строку и весь прежний журнал миграций. Проверены чужой аккаунт, текущий/завершённый/будущий/истёкший поток, явное окончание доступа, pending/cancelled, HOST, срок до/в момент границы, отозванный токен, удалённый аккаунт, no-store и точные спецсимволы кода. Те же16 групп повторены на установленном коде.
- Сборка94 публичных файлов, статические ссылки/структура, синтаксис и scoped Impeccable layout detector `[]`.

Замечания проверки исправлены до выпуска: Safari не фокусирует кнопку при обычном касании, поэтому после отметки фокус задаётся явно; тестовый Prisma resolve направлен на настоящий каталог новой миграции. Ошибочные попытки выполнялись только на отдельной базе, рабочую базу не затрагивали.

Отдельная база создана из структуры без личных строк; перенесены только метаданные журнала миграций. После проверки база, роль и файл её пароля удалены. Тестовых записей в рабочей базе, OpenAI и уведомлений0. Привязка предоставленной настоящей записи — отдельное прямо порученное действие: первый разбор15октября по явному ответу Альмиры, независимо от метки времени внутри ссылки. Значения не включены в Git, отчёты и публичные файлы.

Физический iPhone/Telegram и воспроизведение предоставленной записи пользователем остаются непроверенными. Браузерные тесты используют учебную запись и заглушку API; настоящий Zoom и системный буфер не вызываются.
